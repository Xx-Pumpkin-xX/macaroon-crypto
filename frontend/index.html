Share a file with a link that can be narrowed, never widened.

Anyone can upload a text file, no account needed. The browser encrypts it first, so the server only ever stores ciphertext. Access is handed out as links carrying a macaroon: a token anyone can make weaker, nobody can make stronger, and the owner can take back.

See who can reach the file Try it yourself

Three things the design promises

The server cannot read your file
The browser encrypts it with AES-256-GCM and a fresh key k. That key travels after the # in the link, and browsers never send that part to a server.
A link can only get weaker
Each limit (read only, expires at, share ID) is chained into the token with HMAC. Anyone holding the link can add a limit. Removing or changing one breaks the signature.
The owner can take a link back
Revoking a share blocks that link and every link made from it. Other links keep working.
